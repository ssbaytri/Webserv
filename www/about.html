About Webserv

An exploration into the mechanics of HTTP.
Written entirely in C++98 using strict non-blocking I/O.

The Mission

Webserv is a rigorous 42 Network project designed to challenge our understanding of network programming. The goal is to write a fully functioning HTTP server from scratch, simulating the core features of NGINX without relying on modern frameworks.

Core Mechanics

Built around the power of multiplexing (using select, poll, epoll, or kqueue), the server relies on a single-threaded event loop. It handles everything strictly through non-blocking I/O, ensuring that a slow client never stalls the server.

Features Supported

  • HTTP/1.1 Compliant: GET, POST, and DELETE methods.
  • Configuration: Advanced server block parsing similar to NGINX configurations.
  • Virtual Hosting: Multiple servers on the same or different host:ports.
  • Static & Dynamic: Directory listing, static file serving, and dynamic Common Gateway Interface (CGI) execution.

Under The Hood

  • Language: Strictly C++98 compliant.
  • Memory: Complete absence of memory leaks and strict memory management.
  • Networking: Custom socket binding, listening, and robust chunked request parsing.
  • Resilience: Extensive error handling for HTTP statuses and malformed requests.
